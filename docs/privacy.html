微光 (Glimmer 4K) 隐私政策

最后更新日期：2026年11月

1. 核心隐私承诺：100% 本地存储，零云端上传

「微光 (Glimmer 4K)」高度重视用户的个人隐私与数据安全。我们在此郑重承诺：本应用不会收集、存储、上传或向任何第三方共享您的任何个人身份信息、拍摄的视频、录音或浏览记录。

您使用本应用拍摄的所有视频与音频文件均 100% 存储在您 iPhone 设备本地的应用沙盒中，完全由您本人掌控。

2. 设备权限使用说明

  • 相机权限 (Camera)：仅用于为您提供 4K / 1080p 视频录制功能。
  • 麦克风权限 (Microphone)：仅用于在录制视频时同步采集现场音频。
  • 相册写入权限 (Photo Library Add-Only)：仅当您主动点击“存相册”按钮时，用于将您选中的视频保存到您的系统相册。
  • 面容 ID / 触控 ID (Face ID / Touch ID)：仅通过苹果系统原生的 LocalAuthentication 框架在设备本地验证身份以解锁您的应用内视频相册，本应用无法访问您的生物特征数据。

3. 联系我们

如果您对本隐私政策或应用使用有任何疑问，请通过 GitHub Issues 或官方技术支持页面与我们联系。
